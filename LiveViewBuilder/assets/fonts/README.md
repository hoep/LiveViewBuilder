# Fonts (self-hosted)

Alle Schriften sind frei unter der **SIL Open Font License 1.1** und werden lokal
ausgeliefert (Route `?api=font&file=<name>.woff2` in `handler.php`) - kein externes CDN.
Es sind variable Fonts (latin-Subset), d. h. eine Datei deckt den ganzen Gewichtsbereich ab.
Bezogen von den `@fontsource-variable`-Paketen.

| Datei | Familie | Rolle | Copyright | Projekt |
|-------|---------|-------|-----------|---------|
| inter-wght-normal.woff2 / inter-wght-italic.woff2 | Inter | UI-Sans (Default) | 2016 The Inter Project Authors | github.com/rsms/inter |
| lora-wght-normal.woff2 / lora-wght-italic.woff2 | Lora | Serif (Claude-Skin) | 2011 The Lora Project Authors | github.com/cyrealtype/Lora-Cyrillic |
| fraunces-opsz-normal.woff2 | Fraunces | Display-Serif | 2020 The Fraunces Project Authors | github.com/undercasetype/Fraunces |
| jetbrains-mono-wght-normal.woff2 | JetBrains Mono | Mono | 2020 The JetBrains Mono Project Authors | github.com/JetBrains/JetBrainsMono |

Die vollständigen Lizenztexte liegen je Familie bei: `LICENSE-Inter.txt`, `LICENSE-Lora.txt`,
`LICENSE-Fraunces.txt`, `LICENSE-JetBrainsMono.txt`.
